# GS13 to Paradise port

Work in progress; not a complete GS13 port.

Source: sheepishgoat/GS13-Blubberstation@ec3ad13bd34b64451813004e32892d49de745404.
Base: ParadiseSS13/Paradise@7084a06407db70b41389045dd38f54ae3eb2d1f1.

The initial weight, preference, equipment, and chemistry integration compiled with BYOND 516.1666 with zero errors and zero warnings before the temporary workspace was cleared. These changes are being restored and committed here. Runtime validation has not completed and is not claimed to have passed.

Remaining work includes body/clothing rendering, fullness, helplessness, transformations, atmosphere/MILLA, calorite, machinery, weapons, magic, diseases, genetics, species, organs, maps, jobs, research, food/drinks, and inherited systems. The source contains 302 modular_gs DM files plus changes outside that module.
